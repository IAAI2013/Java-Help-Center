# Java Help Center

A simple and educational Java Help Center that explains important Java programming concepts in a clear and beginner-friendly way.

This project includes **two versions**:

- **GUI Version** (`HelpCenter_vGUI.java`) – Modern dark-themed window application
- **Console Version** (`HelpCenter_vBash.java`) – Lightweight terminal version

---

## Features

### GUI Version
- Clean dark theme
- Search bar to quickly find topics
- Clickable topic list
- Detailed explanations with syntax and examples
- Copy explanation to clipboard
- Modern and easy-to-use interface

### Console Version
- Simple numbered menu
- Same detailed explanations as the GUI version
- Works in any terminal
- Lightweight and fast

---

## Topics Covered

- if / else
- switch
- for, while, do-while loops
- Enhanced for (for-each)
- break & continue
- return
- try-catch-finally
- throw / throws
- assert
- class & object
- methods & constructors
- this, static, final
- inheritance & interfaces
- super & abstract
- arrays & String
- packages & import
- synchronized
- enum
- lambda expressions
- records (Java 16+)
